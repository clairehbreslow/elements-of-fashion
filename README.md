# Elements of Fashion

An illustrated fashion collection inspired by the periodic table. The site
presents 36 original drawings in atomic order and links each look to its
full-resolution PDF.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The static site is generated in `dist/client` and deployed to GitHub Pages by
the workflow in `.github/workflows/deploy-pages.yml`.
